# Top10 第二轮机制研究：先厘清赚的是什么，再判断什么时候退出

日期：2026-09-08。家族：`BIN-1D-MCSM-L10`。

## 本轮结论

**仍未得到可以实盘运行的策略，但把问题往前推进了：确认极端负资金费确有官方来源，量化了每日等权与持有赢家的巨大差别，并否决了一个日级“转弱就整篮子退出”的表达。** 没有搜索参数，也没有用降低仓位换取漂亮回撤。

优先级应从“加一个市场开关”转为：统一固定数量账户，分开归因价格延续、权重再平衡和负资金费，然后研究单个领涨币的趋势失效。后者只是下一轮问题，不是本轮发现的新 Alpha。

## 1. 为什么这次不再给一个新的总收益率

本轮严格分两条证据轨道：

| 项目 | 旧账复现 | 新价格机制诊断 |
| --- | --- | --- |
| 目的 | 回答原数值怎么来的 | 判断每日状态是否有助于保留月度赢家 |
| 输入 | 原冻结脚本、旧名单、原 cache / artifacts | 明确固定的 V3 组合、1d v2、874 个历史观测代码 |
| 持仓 | 月换名单，但每天固定等权 | 月初每腿 10%，随后固定数量 |
| 时间 | 保留原来有缺陷的月初 00:00 / 月末 close | 信号完成后统一延迟 24h，用次日 open 做价格观察 |
| 成本 | 原账口径，仅用于复现 | 独立月全开全平，按实际成交名义金额收 14bp/边 |
| 资金费 | 核对原公式、集中度与源事件 | 不加入尚未核实的资金现金流 |
| 可报告内容 | 代数差异，不能恢复旧绩效有效性 | 独立月/事件价格标签，不能当完整账户净值 |

新轨只分析 **2020-08 至 2026-06，71 个入选月份**。其中 Top10 完整价格路径 68 月；BNX、VIDT、ALPACA 分别导致 2025-03、04、05 月路径不完整，保留为缺失。固定市场篮子完整月只有 36 个，不能按未来存活重选基准。213 个日级 landmark 中，119 个同时满足状态、完整未来价格及不跨月要求。

输入本身 874 / 874 标的均通过价格启动检查，640,378 行中 53,272 行不可用于连续窗口，原样保留。**输入通过不等于上述每一个持仓窗口通过**。开盘价格还被整日有效性掩码做事后观测审查，不能把 `entry_valid` 当成开盘时已知的可成交资格；本轮不借此重选第 11 名补位。后验完整样本仍可能存在覆盖偏差。

全部历史已被研究使用过，不叫 OOS。没有跳过缺月连乘，也没有新的 CAGR、Sharpe、账户最大回撤或 promotion。

## 2. 原策略其实有一项隐藏的仓位机制

旧实现每日把权重放回 10×10%，但只按目标权重变化收成交费用，遗漏价格漂移引起的再平衡。上涨币被不断卖出、下跌币被补回，这与“月初买强者，持有一个月”不是一回事。

同旧名单、同旧价格端点的纯价格代数桥：

| 月份 | 同篮子每日等权 | 月初固定数量 | 差异 |
| --- | ---: | ---: | ---: |
| 2021-07 | +54.10% | +87.57% | +33.47pp |
| 2025-09 | +95.36% | +158.60% | +63.24pp |
| 2026-05 | +32.66% | +124.14% | +91.49pp |
| 2026-06 | +15.25% | -11.48% | -26.73pp |

这不是“固定数量一定更好”的证据，而是**持仓方式直接决定是否保留超级赢家，也决定赢家崩跌时暴露有多大**。原回测的 Alpha、再平衡效应与成交成本此前混在一起，不能只改止损比较收益。表中旧价格仍保留不可交易/身份等问题，仅用于解释代数差异。

详见[资金费及旧记账审计](funding-source-20260908.md)和[逐月价格桥](../artifacts/funding-source-20260908/legacy-price-accounting-bridge.csv)。

## 3. 大额负资金费不是简单的重复数据，但利润金额还不能确认

旧账 2026-06 的资金费算术贡献是 **+30.7266 个百分点**，其中 HOME +11.6091、LAB +11.0504、H +7.1112，合计占 96.89%。三份官方月档及 CHECKSUM 独立取回，1,235 个事件通过完整月份的唯一小时映射后费率逐条一致；原生时间与继承整点时间存在最多 22ms 的表示差异，已留映射而未改湖。

因此至少可否定“这些巨额累计费率只是重复相加的假象”。但全旧持仓对应的 97,529 条新版事件均缺结算标记价格，760 个资产月仅 20 个处于完整已证明日历片段；另有 123 个旧持仓日缺费率却被填零。

真正固定数量的资金现金流是 `-Σ(q × 结算标记价格 × 费率)`，不是 `-0.1 × Σ费率`；结算时还必须实际持仓。动态结算频率与金额公式以[Binance 官方说明](https://www.binance.com/en/support/faq/detail/360033525031)为依据。**费率原值核验通过，不等于原资金费利润金额通过。**

“领涨 + 持续负资金费”值得独立归因，但不能仅凭此认定发生挤空，也不能把费率当成无风险收益。该判断不只影响收益大小，可能影响对整个策略赚钱来源的解释。

## 4. 日级转弱退出的测试结果：不采纳

事前固定两个直观状态：月初市场池中最近 7 日上涨比例是否超过 50%；Top10 最近 7 日是否跑赢同一固定市场篮子。只使用已闭合日 K，不扫描窗口和阈值。从持有满 7 日起，首次两者同时弱，信号后 24 小时退出，不再入场。

在 68 个可配对独立月份中，46 月触发：

| 指标 | 结果 |
| --- | ---: |
| 基线月价格扣成交成本平均值 | +8.61% |
| 提前退出版本同口径平均值 | +4.61% |
| 配对平均差 | **-4.01 个百分点/月** |
| 3 个月时间块重采样，配对差 5%–95% 区间 | -7.77 至 -0.37pp |
| 避开损失合计（每月相同独立初始资本） | 288.53pp |
| 错过上涨合计（同口径） | 560.87pp，约为前者 **1.94 倍** |
| 原正盈利月份利润保留 | **67.21%** |
| 原最高收益 10% 月份的正利润保留 | **77.35%** |

这里的月均值、各月 PnL 合计不是可实现账户收益，且没有资金费。重采样只是已揭示历史的描述性稳健性区间，不是干净检验的显著性证明。

按年份，提前退出仅在 2022 和 2025 的有效样本改善，2020、2021、2023、2024、2026 均降低价格利润。逐一剔除任一年后，总体配对差仍负；剔除最好基线月后仍 -4.06pp。因此不是只被某一个年份或一个最大赢家拖累。

在同时具有完整市场路径的 36 月内，扣除同日期市场篮子提前退出效果后的平均差为 -0.26pp，区间 -3.83 至 +3.55pp；既没有证明选择性改善超额，也不能把 Top10 的 68 月绝对结果与这个 36 月子集直接混比。

### “已经盈利后转弱”反而是主要误杀区域

- 35 个触发月此前曾经盈利：提前退出平均少赚 **7.88pp**；触发时，之前的最高已知收益平均 +14.83%，已经回吐 13.18pp。信号来得不早，但后面仍常有上涨。
- 11 个从未建立盈利的触发月：平均改善仅 +0.31pp；不足以支持另一条独立的有效过滤规则。
- 例如 2026-05：本轮统一延迟、固定数量口径下，持有到底价格扣成本 +104.33%，双弱退出只剩 +16.84%。这不是上一节旧端点的 +124.14%，两条轨道时间/数据不同，不能混用。

三个固定 landmark 的下一周结果也不支持“最近一周双弱就说明月趋势结束”：以月内先平均、再月份等权计，双弱状态后 7 日绝对收益平均 +6.24%（25 个覆盖月），双强为 +2.76%（23 个覆盖月）；两者超额均值的时间块区间均跨零。不能因此倒过来把双弱当成新买入信号，状态样本及未来覆盖不同、也未证明因果差异。

本轮能下的结论是：**这个具体的周尺度转弱信号，容易把月度行情中的回撤/换手误判为结束，不适合作为整篮子清仓条件。** 这不等于所有日级状态都无效，也不能推广为原 00:15 执行一定得到同样结果。

## 5. 下一轮应该研究什么

1. **先确定唯一固定数量基线，并补齐影响盈亏方向的现金账。** 同一名单/成交时点下，对照真实日等权再平衡和固定数量，计入全部成交；按事件的标记价格、原生结算时间与 q 算资金费，独立处理 BNX、VIDT、ALPACA 的终止持仓。未完成前不发布净值。
2. **研究“赢家是否失去领先地位”，不要再把普通市场回撤直接映射为整篮子退出。** 以资产—月份为事件单位，覆盖所有入选者和失败者，观察赚钱来源是否持续集中于少数币；区分赢家继续领先、赢家轮换、趋势真正终止。检验单腿保留/退出的机制时必须与原固定数量篮子配对，报告漏掉的巨额赢家，不只报告止损次数。
3. **把价格与资金费作为两条独立归因，再检验联合状态。** 先问负费率是否补偿价格风险、收益是否可核算，再问当时可知的费率信息是否改善领涨延续识别。不能围绕 HOME/LAB/H 这三个事后案例找参数。

本轮止步于诊断，`not promoted / not live-ready`。研究资料不构成生产交易授权。
