# Top10 机制研究：选币优势、入场前资金费与单币退出

日期：2026-09-10。家族 BIN-1D-MCSM-L10。本轮研究已揭示的历史，不是盲测，不代表实盘收益承诺。

本轮三项研究与8个账户、独立复算均已完成。最有用的进展是：**固定单币退出保留了大部分大赢家利润，含费估算累计收益由+10,084.17%提高到+13,663.98%；但最大回撤仍91.92%，还不能实盘。** 负资金费没有表现出适合作为入场门槛的总收益优势。

## 本轮具体做了什么

只检验三个事前确定的问题，没有扫描参数：Top10 是否优于同月相似币；入场前72小时负资金费是否提高后续总收益；一个固定单币退出规则是否能保留赚钱机会、减少亏损。原月度 Top10 入场不变。

共同历史范围为 **2020-03-01 00:15 至 2026-07-01 00:15 UTC，76个月、760条持仓腿**。币池仍为 Binance USDT 永续，保留 Binance 原生股票/TradFi 永续，不增加外部现货美股。沿用两处已确认的身份错误修正：2026-01剔除跨身份LIT后按原排名补Q，2025-05剔除跨合约AERGO后补LAYER，其他758腿不动；这不是币种改名映射。

手续费每次买入/卖出0.1%，通常滑点每边0.04%，单币退出另做0.08%滑点压力对照。普通调仓和主动退出只用00:15参考开盘价及此前已闭合15分钟的活动信息，不使用成交所在K线之后才能知道的成交量。BNX/VIDT终止结算为例外，保留原终止时点、条件估价、0.1%结算费和0市场滑点。

账户资金费采用上一轮原生标记价优先表，原基线累计收益 **+10,084.17%**，不是原中心估算版本的 **+10,085.43%**。原中心也已有1,233笔原生标记价，本轮基线采用3,695笔原生标记价优先表；两者区别只在已冻结的结算估值更新。本轮先复现前者再比较新规则，不能拿不同基线制造改善。

本轮不再查询被拒绝的官方资金费API，新增15分钟端点仅通过固定本地数据的研究启动接口取得。原文件、数据湖、旧会计内核与旧结果均保留。

## 1. Top10 选币比相似币好吗

结论：在可比较历史里，Top10 平均赚得更多，但优势不是多数月份稳定发生的，且匹配后风险仍未完全相同。

每个月从原有合格池中，为10个Top10各找一个非Top10对照。要求同一观察到的资产类别，按照事前30日成交额和波动率做标准化距离最小的整体匹配，不重复使用同月对照；先锁定650个配对，再提取未来标签、计算比较收益。最终61个可比月份分布在2020-08至2026-05；唯一股票永续配对所在2026-06整月标签不可用，因此本项最终结果不含股票永续样本，不能外推到股票。

| 61个可比月份，不计资金费、扣同样交易成本 | 结果 |
| --- | ---: |
| Top10 平均月回报 | +12.5947% |
| 对照篮子平均月回报 | +6.0064% |
| Top10 减对照，月均差 | +6.5883个百分点 |
| 月差中位数 | -0.3754个百分点 |
| Top10 跑赢月份占比 | 49.18% |
| 3个月区块重采样，均差95%描述区间 | -1.8521至+13.8692个百分点 |

这里每个月独立全开全平、成本后等权固定数量；不是原账户同名净额换仓，也不是跳过缺月拼出的连续账户。以上“平均月回报”不能当作每月都能获得的利润，更不能直接乘12或连乘成年化。

剔除任一年后，剩余可比月份的平均差仍为正，范围+4.31至+8.36个百分点；但2023年单独的平均差为-2.42个百分点。在事前锁定的65个月650个配对中，平均日波动仍是Top10 **11.30%**、对照 **9.80%**；这个匹配质量分母不同于最终61个可比月。不能说已经去掉全部风险差异，更不能称“纯Alpha已证实”。正均值、略负中位数与不足一半的胜率，符合少数大赢家拉高收益的形态；本项没有直接观测投资者资金流或证明其因果来源。

覆盖完整披露：原76个月中，65个月可以事前匹配；11个月因事前价格/同类对照数量不足而整月不可匹配。另4个月因对照退出前活动无效而标签不可用：2023-05 COCOS、2023-11 TOMO、2025-10 HIFI、2026-06 D。没有填零、换币或按未来结果重新匹配。这些缺口也限制了对整个历史币池的外推，不能因为原因已解释就视为不存在。

5批新的本地启动返回补齐98根既定目标K线。650个Top10入场价、649个普通退出价与原修正版全部相同，另1个VIDT终止腿保留原条件估价。独立逐腿现金拆分与主计算最大差小于2.8e-15。

证据：[选币摘要](../artifacts/mechanism-round-20260910/selection/summary.json)、[完整76月比较及缺口](../artifacts/mechanism-round-20260910/selection/monthly-comparison.csv)、[独立算术核对](../artifacts/mechanism-round-20260910/selection/arithmetic-qa.json)。

## 2. 入场前负资金费能提高总收益吗

结论：能提示后续更容易收资金费，但没有显示总收益优势，不采用“只买负资金费Top10”的入场门槛。

只用月初00:00之前72小时已经观察到的通常资金费率，严格排除00:00同刻结算及之后的事件。760腿中，事前费率和为负222腿、非负538腿；65个月两类都有持仓，按同月两组平均收益相减，避免不同时代行情混在一起。

| 同月负组减非负组 | 平均差 |
| --- | ---: |
| 后续价格收益 | -12.8265个百分点 |
| 后续资金费现金 | +6.9086个百分点 |
| 扣独立往返成本后的总收益 | **-5.9001个百分点** |

负组总收益更好的月份占44.62%；3个月区块重采样的95%描述区间为-26.18至+13.54个百分点。2025-09及以前差-5.30个百分点，2025-10起9个月差-9.65个百分点。排除原中心账户资金净现金贡献最大的10个持仓月后仍差-1.35个百分点；这是事后集中度检查，不是删掉这些币重做策略。

本项按每腿1 USDT初始名义计算价格差、实际持有区间的资金现金和独立成本，不是新组合账户。资金单独变好，并不能抵消价格变差。

对盈利来源的解释更具体了：入场最近一笔非负的580腿中，448腿在持有期间随后观察到负费率，持有期间首次出现的中位时间为入场后4.66天；并非这些币在入场前从未负过。MYX、AIA、LAB的一些大贡献持仓，入场前72小时费率和及最近一笔资金费均为正，先要求负资金费会挡掉这些后来赚钱的机会。反例同样重要：H在2026-06虽收到相当于初始名义44.33%的资金费，但价格跌81.96%，扣成本后仍亏37.79%，收钱不等于总收益赚钱。

收到的资金现金里，发生在标记价已达入场2倍以上的比例：沿原中心回测账户模型持仓数量按现金额加权为38.855%；各腿初始名义固定为1后为55.371%。两者分母不同，也不是新规则的资金费保留比例。数据说明资金收入有一部分出现在价格已经大涨后，不能据此直接证明轧空或特定交易者行为。

完整性限制没有消失：仅18/760个事前窗口与已有明确发布日历相符，其中只有2个负组；742个窗口的完整日历未证明，757腿还沿用Unspecified视作通常资金费的模型假设。因此结果只是既有观察数据的机制检查，不能把18个窗口扩大称为整个信号或资金账户认证。

独立重新读取原固定资金快照、不调用主研究的信号/收益函数，复核了9,489个前置事件、97,421个未来事件、760腿和65个同月差；最大逐腿差4.44e-16，逐月差2.22e-16。BNX/VIDT还独立解析原1分钟指数原文核结算估价，终止收0.1%费用、市场滑点为0，与原模型一致。

证据：[资金信号摘要](../artifacts/mechanism-round-20260910/funding-signal/summary.json)、[逐月配对](../artifacts/mechanism-round-20260910/funding-signal/paired-month-differences.csv)、[独立复核](../artifacts/mechanism-round-20260910/funding-signal/independent-recheck.json)。

## 3. 单币退出：保住了大赢家、提高了收益，但仍不能实盘

唯一新增规则：某币日收盘跌破此前20个有效日收盘低点，而且近7日收益落后于月初固定其他9币的中位数，连续2个持有后的已闭合日满足，次日00:15卖掉这一个币。当月不买回、不补位，其他币数量不变，下月仍按原Top10重新分配。

实际完成76个月、8个独立复利账户。初始资金均为100,000 USDT，每月成本后权益10%/腿，同名按净额换仓，期末清仓。没有改动基线的日期、名单、成本或本金算法。

### 盈利保留与代价

- 314次单币退出，175次提高独立价格腿回报、139次降低；含资金费则172次提高、142次降低。不是每次都卖得更好。
- 所有18,124个持仓信号日都保留，170个特征未知日重置连续计数并继续持有，没有把缺失当弱势或缩小其他9币的分母。314个退出目标与另一个逐日字面算法逐条一致。
- 按每条持仓初始名义固定为1 USDT、扣独立往返成本：价格侧原310条盈利腿保留 **95.30%** 利润，原760腿中收益最高的76条保留 **99.11%**；含费侧原312条盈利腿保留 **96.03%**，最高76条保留 **98.64%**。这里“前10%”指原760腿中的76条，不是盈利腿数再取10%，也不是账户总利润保留率。
- 平均日末持仓由约9.99个降为8.03个；含费平均持仓名义/权益由98.43%降至83.34%。存在减少在场资金的作用，不能把全部收益差都称为新增选币优势。
- BNX/VIDT两条均在原终止前触发普通退出，候选不再二次终止结算；基线继续沿用原条件终止估价。其他数据及实盘完整性问题并未因此消失。

固定原含费基线的模型数量、不让后续本金变化，仅检查这314次退出的直接影响：提前卖出避免后续下跌 **3,462,131.07 USDT**，但错过后续上涨 **2,834,896.67 USDT**，价格合计改善 **627,234.40 USDT**；少付资金费147,033.17、同时少收524,421.75，资金净现金反而减少 **377,388.58 USDT**。这个拆分不是另一条可自我融资的策略，也不能直接等于两个完整账户的终值差。

完整含费候选的资金净现金却由6,869,920.49增至9,130,656.24 USDT，原因包含后续本金及数量变化；不能说退出规则本身提高了每笔资金费收入。完整现金关系为：初始100,000＋价格4,805,372.15＋资金9,130,656.24－手续费194,319.88－滑点77,727.95＝期末13,763,980.55 USDT。

## 本轮结论与下一步

三项都进行了实际研究，不是复述原方案：选币做了相似币对照，资金做了严格事前特征检验，退出做了8个完整账户。当前结论是 **保留Top10入口；不采用负资金费入场门槛；将这一固定单币退出保留为有改善迹象的研究候选，但不用于实盘。** 它没有解决深度回撤，也没有经过独立新历史检验。

对盈利来源，目前能支持的解释是：历史Top10价格回报有较大的右尾，一些大涨持仓还在持有期间收到资金费。不能把它简单说成“每月多数领涨币继续涨”，也不能说“提前挑负费率就能套利”；赚钱效应扩散、投机者对立、轧空等更具体的行为因果没有在本轮直接验证。

接着研究最有价值的问题，是**如何保留领涨币的上涨和持有资金收益，同时减少全市场一起跌时的损失**。现有单币规则用其他9币作参照：较强的币也可能跟着整体大跌，而且下个月仍会照常重建仓位。因此应先独立分解共同市场涨跌和领涨币自身延续的贡献，再决定是否值得另做一个带市场对冲的版本；这里没有运行或批准做空/对冲策略，不能提前宣称对冲一定保住利润。不继续调20/7/2寻找更好历史曲线。
