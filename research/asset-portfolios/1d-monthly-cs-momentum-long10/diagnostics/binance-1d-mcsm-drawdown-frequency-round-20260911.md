# Top10：大回撤从哪来、多退出几个币、月频与周频

研究日期：2026-09-11。本轮完成四条原账户的回撤拆分、八条扩大退出账户，以及四条同区间月度对照账户，均独立核账通过；另四条周频账户因历史下架结算输入缺失停止，不能给全期收益。所有成功账户的逐月持仓、盈亏、年度结果与失败周频的事前选币计划均已整理，不替代任何旧冻结报告。

## 1. 已完成的结论

大回撤主要是持仓币的价格损失，不是资金费或手续费吃掉利润。熊市共同下跌很重要，但不能把整个策略的长期回撤都归咎于大盘：不计资金费账户从2021-11-26高点至2025-08-03谷底跌95.43%，同期BTC反而涨90.73%，ETH跌25.08%。不断轮入下一批上月赢家，并没有自动解决熊市后账户恢复的问题。

本轮固定比较表明，第一次出现弱币时卖弱的五个、保留其余币继续原退出规则，明显好于第一次出现弱币就全部清仓。但它仍有87%—88%回撤，2022年仍亏74%—75%，还不是能直接实盘的版本。

所有历史已经看过，不称为盲测或独立未来样本。原策略及原单币退出不改；本轮没有对冲回测、参数搜索、生产部署或下单。

## 3. 大回撤来自哪里

### 3.1 真正损失的是币价

含观察资金费的B0最大回撤：2021-11-26至2023-09-01，权益从5,112,138.69降到335,902.38 USDT，净亏4,776,236.30 USDT，回撤93.43%。

| 真实模型现金组成 | USDT |
| --- | ---: |
| 币价损益 | -4,764,264.21 |
| 观察资金费损益 | +57,597.45 |
| 手续费 | -49,692.53 |
| 滑点 | -19,877.01 |
| 权益变化合计 | -4,776,236.30 |

这不是“一两个手续费高的币把组合磨死”。最大回撤内159/220个跨月持仓片段价格亏损。2022年120条月度持仓有89条价格亏损，12个月有10个月账户亏钱。含费B0要等到2026-05-06才重新回到此前高点；S1要等到2025-11-08。不计资金费的B0/S1截至2026-07-01都尚未恢复各自高点。

### 3.2 市场大跌解释了一部分，不是全部

在上述含费B0完全相同的峰谷日边界，BTC跌56.05%、ETH跌63.66%。只看数量恒定的完整持仓日，使用此前60自然日、至少45对有效样本估出的市场敏感度，拆出以下**统计相关**现金：

| 价格现金分解 | USDT |
| --- | ---: |
| 与BTC/ETH等权市场因子对应的部分 | -2,375,340.16 |
| 模型剩余价格损益 | -2,675,858.25 |
| 完整日但过去样本不足 | -28,058.65 |
| 换仓/退出边界等未分解部分 | +314,992.84 |
| 价格现金合计 | -4,764,264.21 |

不能把它说成“精确一半来自大盘、一半来自选币”，更不能把剩余项叫可交易Alpha。它说明需要同时研究共同下跌和领涨币失速，单做大盘过滤不保证保住领涨延续。市场参照中的广谱币池有39个不同缺价日，未删除事后缺价币或跳日拼指数，因此不给伪完整广谱累计回报。

## 4. 多退出几个币怎么样

先纠正名称：S1是“每个币分别决定退出”，不是“一个月最多卖一个币”。76个月有70个月触发，65个月卖出至少两个币，最多8个，合计314次，平均每月4.13个。X5本轮456次退出、月内最多9个；X10为70个月各退10个。

### 4.2 为什么不能只把X5称为更优版

X5价格结果有改善，但含资金估算的最终权益只比S1高3.03%，多416,424.87 USDT；不是收益再次大幅跃升。按每条原持仓相同初始名义比较，S1保留原盈利腿96.03%、最大76笔利润98.64%，X5降至78.01%和82.58%。X10只保留最大76笔利润36.21%，平均持仓降至3.41个币，回撤仍高达87.33%。

固定原B0价格账户数量看，X5少承受628.28万价格亏损，同时放弃492.87万后续价格收益，差额有利；X10少承受1,255.96万亏损，却放弃1,415.83万价格收益，得不偿失。这是解释性现金比较，不是另一个自融资账户。

资金也要分清：固定原含费B0数量，X5因提前退出少得到净资金现金140.84万；但实际X5账户资金收益比B0多118.05万，是数量和后续本金路径也改变了，不是卖掉币凭空增加了该币的资金收入。

这轮支持的具体结论是：**弱币出现不等于整篮子赚钱效应结束，清掉所有币会把仍延续的强币一起卖掉。** X5保留研究，X10这一条具体规则停止；不据此认定所有市场状态开关都无效。两者都没有实盘资格。

## 5. 周频试了，但现在还不能判断赚不赚钱

## 8. 接着研究什么

1. 先补BZRX、KEEP的历史终止证据，或在独立的新执行规则中明确“公告后不新开即将下架的合约、提前清仓”。必须证明公告在当时已发布、成交价当时可得，再重跑原定月/周比较；这轮失败结果仍保留。资金现金补全另行处理，不把价格可用等同永续净收益可用。
2. 保留X5作研究对照，停止当前X10规则。重点检验“剩余强币仍在延续”和“整篮子赚钱效应已共同失效”能否在当时区分，而非继续搜退出数量的最优参数。必须同时看少亏了多少、错过多少大赢家以及熊市后再入场的亏损链。
3. 原策略的利润仍高度依赖少数强行情，前轮匹配同波动/流动性对照没有证明稳定选币优势。这轮也没有解决这一点；不能因为X5历史收益更高就宣布找到了可重复Alpha。下一步要验证赚钱效应与趋势延续的条件，而不是只把回撤百分比压低。

本轮没有合格实盘候选。X5有继续研究价值；月度28日榜更高历史收益伴随更深回撤；周频收益问题尚未被可靠回答。
