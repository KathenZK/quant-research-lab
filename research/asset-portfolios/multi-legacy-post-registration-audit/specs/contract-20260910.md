# 早期策略落档后回放规则

研究于 2026-09-10 建立；在本轮查看回放结果前固定以下规则。

- 这是跨家族诊断，不是新交易策略，不改原参数或策略状态。
- 清点 HYPE 与 BTC、ETH、SOL、BNB、TRX 的早期日内家族，优先 15m、30m、1h；有清晰 spec 的冻结候选也可纳入。只剩搜索记录、没有唯一冻结配置的家族必须列明，不临时选成绩最好的行。
- 每家族主选最后已落档版本（按家族自身版本规则），冻结文件/主账/原研究样本尾一起核对。时间以可核验 spec 或版本注册证据为准；只有日期时从次日 UTC 开始；若原研究已使用更晚数据，起点不得早于该数据尾。Git 首次提交只能证明最晚已落档时间，不伪称真实研究起始时间。
- 信号预热使用起点前数据；主结果从起点空仓开始，只接受起点后产生的信号。记录强制期末平仓与未平仓估值方式；不只报告已盈利的平仓单。
- 原模型复用优先。原 spec 与脚本时序冲突、mark 触发缺失、未来信息、精度/成本差异必须明示，不能改用有利假设。
- 统一已闭合比较截止为 2026-09-05 15:00 UTC；价格经固定组合 `binance.v3.research_inputs.v2` 完整启动检查。15m预热始于2025-05-30 10:30 UTC，1h始于当日11:00 UTC。后续回放消费本轮 API 返回并哈希固定的研究派生物，不直接读旧 cache。
- 主表保留原手续费、滑点、杠杆。原 spec 不含资金费者不伪称完整净收益；补充已观察资金费估计值须显著标识。历史结算日历、原生 mark 或身份未通过时，不发布已核准完整净收益。缺费率不填零。
- 按全段、月度及可得的前30天/后段报告收益、最大回撤、交易数、盈亏因子与费用；少于30天或交易很少只说明这段表现，不推断长期仍有效。
- 用户本轮明确要求查看落档之后表现，包含尚未到原盲测到期日的家族；若查看其部分未来段，记录本轮提前揭示，永久标为已揭示历史诊断，后续不得称其仍盲。
- 每个已识别家族须进入清单：完成、无唯一冻结交易配置、数据不足、复现失败或尚未完成各自分开。
