# 用户原始假设澄清：加密中期趋势、MA7参与与事前强势筛选

日期：2026-09-08。性质：用户问题澄清、现有证据审查和后续研究设计；不是新回测结果，不修改P1冻结合同或既有失败结论，不登记/晋升策略。

## 原始问题

用户希望验证：趋势一旦出现可观测的启动证据，是否具有中期延续性；加密急涨急跌中是否存在能够实际捕获的收益；MA7穿越是从K线上观察到的参与线索；如果它只在某些强势上涨/下跌状态有效，能否在下单前识别这些状态并筛选机会。

原始逻辑应保持为：趋势延续假设 → 事前识别适用状态 → MA7触发参与 → 持有和退出保留收益 → 全成本账户价值。不能用同一规则在多数币全时段失败，替代对整条逻辑的检验；也不能因失败就默认要求用户转向传统期货或carry。

“超过半数独立标的有效”仍是原任务已失败的明确命题。本澄清不把它改判成功。它也不能成为判断所有条件趋势机制是否存在的唯一标准；泛化还需要看同一事前规则是否能跨币、跨时期识别可交易机会。组合价值和同日选币增量分别报告，不能偷偷替代原始总事件/账户目标。

## 文献支持与尚待检验的推论

[百年趋势研究](https://www.aqr.com/-/media/AQR/Documents/Insights/Journal-Article/AQR-JPM-Fall-2017.pdf)考察1880–2016、多个资产类别，使用1/3/12个月趋势信号和月度调仓；它为继续研究趋势提供外部依据，没有验证7日均线、加密特定日周尺度或每个启动事件必然延续。[加密研究](https://www.nber.org/papers/w24877)也记录过时间序列动量，但其历史和少数主要币样本不能外推为当代全山寨市场的普遍定律。

急涨急跌是波动和路径幅度观察；它是否带来更多可预测的延续、是否足以覆盖误报与执行成本，需要单独验证。高波动随机路径也可能呈现很大的事后最高浮盈。

## 后续最小研究链

### 一、定义趋势的可观测起点和事后评价

先冻结“中期”的日历跨度及主要检验，少量相邻跨度作稳定性检查，不能遍历后挑最佳。未来方向位移、顺逆向路径、持续时间、首次触及顺序和期末收益共同描述后续走势。评价标签不使用MA7构造，防止用MA7定义趋势又证明MA7有效。

必须区分：用于实际决策的当时状态与触发，只能读过去；用于衡量趋势是否发生、遗漏和捕获的未来标签，只能用于评价。期末回报、首次触及与最大有利幅度分别保存，不能用任何一个替代完整可捕获收益。

### 二、把强势拆为竞争的时变状态假设

至少区分“已经强并继续强”“此前弱、现在开始转强”“已有趋势中回调后再启动”；做空独立检验。这些是假设类别，不是承诺全部运行的特征网格。先查看已有数据证据和失败，保留少数有明确判别意义的描述。

强势应由下单前的相对市场表现、自身价格结构、波动与参与度形成；不把事后暴涨币名、全样本收益或当前市值当历史选池条件。突破前状态使用t−1及更早；已收盘突破日信息可以作为t收盘确认特征，但须与前置状态分开，成交从之后可执行时点开始。

同一币进入和退出强势状态的全过程都保留。市场普涨择时、同日相对选币、币种固定效应用于解释贡献；不把其中一个必须显著强加为总策略盈利的必要条件。

### 三、固定四格，区分筛选与入场

| | 简单因果方向入场 | MA7穿越入场 |
| --- | --- | --- |
| 不做强势筛选 | 基础对照 | MA7自身表现 |
| 做事前强势筛选 | 筛选本身的表现 | 用户观察的完整组合 |

四格先固定共同的方向定义、可交易库存、风险预算、持有/退出和费用口径，再计算结果。简单入场可以是在共同方向/资格成立后下一开盘，不等MA7；精确触发、再入场和匹配方案须在回放前冻结。主要比较实际账户总收益与完整机会覆盖，补充事前确定的风险/持仓暴露匹配分析。

MA7无需提供显著独立alpha才能承认完整策略有价值。若筛选有效且简单入场更好，可保留经济假设并简化入口；若组合才有效，则研究交互；若只有全时段做空赚钱，必须披露方向暴露贡献。

### 四、用同一趋势段检查利润如何损失

针对预先定义的全部趋势段和全部误报，统一连接：首次可交易信号、入场延迟、入场后逆向波动、最大浮盈、每次退出/再入场、最终实得利润与全部成本。案例只是全量统计的解释，不从少数赢家倒推新条件。

同一趋势内多次穿越在推断时按趋势段/资产/时间聚类，不能当多个独立成功证据。事后趋势身份只能用于评价和归组，不能让历史回放提前知道“仍是同一趋势”而跳过亏损交易。真实交易使用因果持仓状态，保留反复进出的全部费用。

重点指标：趋势覆盖、未捕获趋势、参与延迟、捕获幅度、最大浮盈回吐、误报频率与总损失、反复进出费用、右尾贡献。趋势策略可以依赖少数大赢家；要检验这些赢家能否事前纳入和跨独立环境复现，不能仅用低胜率/负中位交易收益否定它，也不能用事后峰值宣称可实现收益。

### 五、定位后再修改一个环节

| 观察结果 | 支持的下一步 |
| --- | --- |
| 事前方向/启动条件后的路径不优于适当对照 | 重新审视该尺度的延续假设；不能靠未来趋势标签制造可预测性 |
| 有延续机会，强势分组区分不了未来路径 | 该筛选描述未获支持；保留无条件/其他已冻结分支作为对照 |
| 筛选提高机会质量，MA7造成过晚入场/过多误报 | 有依据只调整入口；不同时搜索退出与选池 |
| 选中趋势但频繁退出，或浮盈大量回吐 | 对固定信号做小规模退出/持有对照，评估多保留利润与新增亏损的净效应 |
| 毛收益成立，全成本后消失 | 研究换手/执行可行性；缺失成本时保持未验证 |

最先需要的产物是“同一批可交易机会的趋势路径—信号—持仓—实际利润连接审计”。它要回答是机会不存在、看不见、进不去、拿不住，还是成本过高。现有失败完整保留；已有正面状态信号在恢复输入/模型复现后才可作为新策略输入。所有新参数、标签和账户规则在实际运行前单独冻结，已揭示历史继续标为诊断，最终确认依赖独立新证据。
