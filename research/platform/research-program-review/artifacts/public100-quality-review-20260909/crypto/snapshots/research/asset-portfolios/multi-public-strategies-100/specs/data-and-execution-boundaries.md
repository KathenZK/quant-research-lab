# 数据与执行边界

## 当前数据状态

遵循仓库 `docs/data-lake-spec.md` 第 1–12 节，所有新获取的市场数据进入统一 `data/raw`。原生 JSON/CSV/ZIP 和官方 CHECKSUM 留在 `raw/source_payloads`；OHLCV 行按真实交易场所、市场类型、周期、来源、UTC 日期分区。所有写入是原子写，独立文件名包含本轮快照版本，不覆盖旧业务文件。

Yahoo 行保留原生 OHLCV 与 adjclose，不补成交笔数、VWAP、quote_volume 或 is_closed。审计覆盖交易所 session 网格、重复键、关键字段有效性、OHLC 合法性和内容指纹；这些检查不等于 trusted schema。保存的元数据区分 NYSE Arca 与 Nasdaq。跨交易所 ETF 日历诊断使用共有美国常规交易日；没有将该映射注册为可信 session policy。

Binance 现货使用官方 15m 月档及 SHA256 校验文件，保留开闭时间、原生成交笔数和成交额。2025 年起的微秒时间戳逐文件识别，不误当毫秒。源层 573,216 行的缺口、重复、非法 OHLC、闭合时间冲突与零成交均为 0。原生档案闭合时间与固定截止相符，但本轮仍按 `raw_unaccepted` 存储。

仓库当前统一启动组合仅发布 USD-M **永续**数据；本清单 D7–D10 是**现货**，不能为套用启动器而替换为永续。这里执行规范第 5 节明确允许的 untrusted diagnostic probing，未宣布现货输入已经进入 trusted 组合，也未借用旧 normalized/缓存得到正式净收益。后续若要正式验收，应建立现货 dataset_id、normalized/derived 发布与相应启动契约，再通过 catalog 严格内容检查；不是把本报告的行质量检查改名为启动通过。

数据读取的明确例外：`prepare_freqtrade.py` 只读取清单指纹逐一核验的本轮 raw 分区，生成可删除 adapter；`backtest_equity_diagnostic.py` 核验全部 raw 分区及源 JSON 的 SHA，再解析保留 JSON，避免十多万单行 Parquet 反复物化。所有数值产物均标 `EXPLORE_UNTRUSTED`。`data/cache/public100` 只供重建和离线引擎适配，不成为其他研究的事实来源。这些路径在消费者检查中按具体函数登记为 raw 生产/诊断，不放宽其他家族门禁。

## 冻结与数值口径

主契约在结果生成前固定；后续月相和到期周使用独立日历补充契约。代码实现改变只用于纠正执行或核算问题，不搜索最佳参数。历史全部作为诊断，不能声称盲测。读过的未来结果不反向调整原规格。

ETF 使用 Yahoo `adjclose/close` 因子同时调整日开盘，形成总回报价格单位。它是供应商复权约定下的组合诊断，分红按总回报再投资方式体现；不是券商真实股数、现金派息与税后逐笔账。一般信号仅用前一完整交易日信息，下一交易日开盘执行；持仓在两次再平衡间随价格漂移。手续费通过交易后权益方程求解，现金不暗中变负；终点按收盘扣清仓成本。多空版本统一额外假定年借券费 3%，周末计息，但没有历史可借券证明，因此不是真实可执行多空收益。

原文与代码不同时，variant 单独命名：A6 的 210 日/每日全仓重分配与文字 10 个月/月度版；A9 的 63 根绝对价格差与文字 252 日相对收益；A29 的源码倒置方向与文字动量方向。A7 仅实现文字的前三等权，源码新增标的分母可能造成过度配置，未冒充原代码账户。A53 仅实现文字 200 日版本，原 200 小时需要另行验证。A20、A22、A31、A40 有日线执行近似，名称含 PROXY。A36 用一月首尾收盘判断；原代码月初时点价格不同，仍是诊断。C4 使用原文 KDA_100 的正动量前五、1/3/6/12 月加权相关矩阵、最近一月波动率、长仓最小方差、VWO/BND 金丝雀与 IEF 防御，**不**用“挑最低波动的几只”代替优化。没有跑杠杆 1.5/2 倍版本。

ETF 一般执行单边 5/10/20 bps 三档成本。A10 的已知定时收盘买、次日开盘卖单独核算，不能把信号 lag 错移为全天持有。C4 与其他策略的参考对照均使用同窗口 SPY 买入持有，考虑两端成本。不同策略的波动与风险暴露不相同，因此总收益超越不等于 alpha 成立。

D7–D10 直接运行审阅过的原 Python 策略、Freqtrade 2026.8 与 TA-Lib，保留来源配置的 $25 钱包、$12 单次初始资金、最多一仓、0.99 可交易资金比例及原白名单顺序。这是一份特定小额账户实验，不能推广成任意资金规模的模型收益。D7/D9/D10 以 15m 明细处理原 4h/1h/30m 信号；D8 原 15m，尚无更细明细。原生 ROI、追踪止损、D7 一次加仓均由框架执行。框架使用当前市场精度/最低订单限制及 OHLC 触价假设，不证明历史委托成交、盘口可得性或滑点。额外成本只用更高手续费做摩擦敏感性，不伪称真实滑点成交模型。禁止真实下单或启停任何实例。

Freqtrade 的最高/最低账户值和浮动回撤从 wallet 轨迹获取，已实现交易回撤另列。报告留存全部 12 次结果 ZIP、策略源码、解析配置、交易、逐期钱包、年度分解；另以逐笔订单金额和双边费率独立核对盈亏与期末资金。资金低于固定下单额时策略会停止开仓，必须报告实际最后交易日。

## 非行情辅助数据

原始月相 CSV 公开源本轮可下载，但只到 2020-11。补充实验使用 ephem 4.2.1 计算月相，派生规则和 hash 放入 `data/features/public100_lunar_calendar_v1`；它不是官方行情或 USNO API 成功记录。已与旧 CSV 重叠季度时刻交叉核对。SEC companyfacts、币安美国站当前列表、BTC OI 单日样本等只作为数据可得性探测留存，没有被当成完整 PIT/历史 OI 研究输入。

## 尚缺的验收条件

原策略语义一致、可信数据入湖/启动、历史股票池与终止处理、历史借券/期权/新闻/OI/资金利率交易合约数据、正确时间执行、费用与容量、多重检验、真正未读时间验证。这些分别记录，不将“代码运行成功”或“原网页显示高收益”当作通过。
