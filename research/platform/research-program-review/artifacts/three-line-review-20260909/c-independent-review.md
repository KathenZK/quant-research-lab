独立算法可复算表达式：

```python
rates = {int(row['fundingTime']): float(row['realizedRate']) for native pages/rows}
marks = {int(row[0]): tuple(map(float, row[1:5])) for closed native mark candles}
funding = sum(q * rates[ts] * marks[ts][0] for held settlement timestamps)
pnl = sum(spot_order_cash_deltas) + short_q * (short_entry - short_exit)
pnl -= derivative_entry_fee + derivative_exit_fee
pnl += funding
# inverse VWAP: sum(contract_fill / fill_price), then contracts / inverse_sum.
# inverse terminal coins:
coin = gross_spot * (1-spot_fee) - N/F*derivative_fee
coin += N*(1/terminal_index - 1/F) - N/terminal_index*settlement_fee
final_equity = 10000 - gross_spot*spot_buy_vwap + coin*terminal_spot*(1-spot_sell_fee)*(1-slippage)
```
