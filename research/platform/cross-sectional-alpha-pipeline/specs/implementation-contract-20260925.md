# 研究基础组件落地契约 · 2026-09-25

本轮落实用户“先把能做的事情全部做掉”的要求。范围是六项已经评估可执行的研究仓库工作：因子边界、独立账户核对、候选恢复、数据能力清单、研究曝光记录、离线信号到净持仓接口。它不是新策略家族，不以找到正收益为目标，不改写旧冻结内核、历史结果或线上运行状态。

## 在结果之前固定的交付与判断

1. 相对强弱必须按独立合约与连续研究段计算；缺失值不向前填充。用双币、段边界、未来扰动、乱序/重复、缓存版本变化验证。列明实际调用方，不把一个共享实现的错误推定为全仓历史污染。
2. 新增小型离线账户参考工具，只处理线性USDT合约的明确成交、数量、费用、资金费和估值。持仓支持多空与部分成交；已包含在成交价中的滑点不再扣现金。初始保证金采用明确固定敞口上限作研究约束，不模拟交易所维持保证金阶梯、强平或撮合。
3. 分数接口只使用决策时刻前已知的值；目标持仓明确资金预算；净订单按目标与当前真实数量之差生成。合并策略时按一个净账户记账，不同时获取虚构的子账户收益。测试中选择规则与资金预算固定，不搜索绩效。
4. 恢复对象优先选HYPE MA7-CAR V3“取消额外预热”的既有冻结价格回放；恢复原规格、固定内核、实际输入及原输出。原18笔等结果仅作一致性锚点，不重新选择赢家。必须离开原项目路径后重放，并核对指标、交易、止损和净值；缺少来源时原样报告缺口，不拿新训练/新数据冒充恢复。
5. 数据清单读取当前固定组合及物理输入，分别记录价格、资金日历、流向字段、身份、结算估值和时间可得性。能做价格诊断不等于能做完整净收益研究。对预先固定的BTC、ETH、HYPE日线范围2025-07-01至2026-09-05，回看30根、向前3根作窗口能力探针，不计算/筛选投资收益。样本确定先于覆盖结果；不以结果挑池。
6. 曝光记录采用追加与内容链校验，记录研究身份、已看窗口、尝试数量及不确定性、选择依据、输入/代码/结果指纹。旧实验只登记可证部分，未知次数不补造；历史观察不追认实时前瞻。

## 证据与边界

- 全部实现进入可复用包或本主题脚本，旧内核保持SHA256不变；新增代码运行必要的经济反例和定向测试。
- 本地证据包与独立恢复演练在授权范围内。异地备份只有明确的用户目的地才可上传；本轮不删除历史产物。
- 针对冻结候选生成前瞻记录合同与只追加日志入口；缺失或迟到记录必须保留，不生成伪造的历史在线决策。没有持续采集/运行的事实，就不称前瞻已启动。
- 新因子净收益实验只有在其精确数据、身份、资金费及账户约束可证明时才启动；否则完成能力矩阵和明确阻塞，不用零资金费或事后挑池规避。
- 这些检查通过证明对应组件的行为与可恢复性，不等于研究平台全面就绪、策略盈利或可实盘。
