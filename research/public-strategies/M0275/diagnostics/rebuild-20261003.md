# M0275 重建与恢复配方

## 已验证的事实

- 输入primary与rebuild都是既有独立网络抓取的25月Binance原生4h快照，本轮实际重新审计各75个源对象及4572行；canonical SHA256均为`9f5cb39c1426ec91098bb8a1b1f0c926b80760e66fe452d6b0c0aa55429d126c`
- 在新的空结果目录，从第二套输入重新运行固定协议，22个输出中的21个逐字节相同；summary除峰值RSS外所有内容相同，见[本地恢复回执](../artifacts/local-recovery.json)
- 本地恢复没有借助原收益复制来生成新结果，但它不是异地备份，也不是本轮再次网络下载。C3远端与私有包由协调者记录
- 已冻`specs/protocol.json`与其全部`frozen_file_hashes`不可覆盖。`prepare_freeze.py`记录本次一次性冻结程序，不用于重新冻结旧版本

## 环境

Python3.12.14；numpy2.3.5、pandas2.2.3、ta0.11.0。精确包/ta文件摘要见`specs/requirements.lock.txt.json`。运行时需`OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1 MKL_NUM_THREADS=1 NUMEXPR_NUM_THREADS=1 PYTHONDONTWRITEBYTECODE=1`，至少5GiB真实空闲磁盘；执行器内部限制地址空间1.5GiB。完整过程不需要TA-Lib或Freqtrade安装。

以下命令从M0275目录运行。`INPUT`须指向已授权且匹配摘要的输入；`PRIVATE`是新的私有工作目录；所有输出路径不得已存在。它们是占位环境变量，不是网络地址。

## 1. 已有输入的验证

```sh
python scripts/compare_rebuild_manifest.py --snapshot "$SNAPSHOT" --output "$PRIVATE/manifest-check.json"
python scripts/audit_raw.py "$SNAPSHOT" "$PRIVATE/raw-audit.json"
```

比较timeframe/schema/builder、75对象bytes/SHA以及canonical输出，再独立核ZIP CHECKSUM/CRC、原字段、网格及OHLCV。检查失败即停；不排序修正、去重、补K、插值或更换输入窗口。

## 2. 若需要重新从官方月档重建

仅在本用途的数据条款/网络读取已经授权时执行：

```sh
python scripts/rebuild_official_bars.py --timeframe 4h --target "$NEW_SNAPSHOT" --terms-reviewed
python scripts/compare_rebuild_manifest.py --snapshot "$NEW_SNAPSHOT" --output "$PRIVATE/rebuilt-manifest-check.json"
python scripts/audit_raw.py "$NEW_SNAPSHOT" "$PRIVATE/rebuilt-raw-audit.json"
```

`--terms-reviewed`是操作者确认已审用途，不是绕过条款的口令。必须新目录，失败保留`.partial`。不要把轻量清单直接传`--expected-manifest`：它没有该CLI期望的protocol键。禁止换域名绕过403/451/认证限制；源档改变或hash不符需新研究版本，不能覆盖旧证据。

## 3. 来源、信号与真实历史回放

```sh
python scripts/fetch_sources.py --target "$PRIVATE/source-copy" --references
python scripts/check_signals.py --input "$INPUT" --source "$PRIVATE/source-copy/Heracles.py" --output "$PRIVATE/signals-qa.json"
python scripts/run_replay.py --input "$INPUT" --output "$PRIVATE/replayed" --spec specs/protocol.json
python scripts/validate_ledger.py --work "$PRIVATE/replayed" --input "$INPUT" --spec specs/protocol.json --output "$PRIVATE/ledger-qa.json"
python scripts/independent_oracle.py specs/protocol.json "$INPUT" "$PRIVATE/replayed" "$PRIVATE/oracle-qa.json"
python scripts/check_execution_prefixes.py --input "$INPUT" --spec specs/protocol.json --output "$PRIVATE/prefixes-qa.json"
python scripts/test_synthetic.py
python scripts/independent_synthetic_tests.py
python -m unittest discover -s scripts -p test_rebuild_official_bars.py -v
```

完整第三方源码仅进入私有source-copy。strategy固定源内容必须符合3867bytes/SHA；参考框架来源不冒充原作者运行环境。官方AgeFilter历史事实证据保存在公开轻量摘要，原HTTP raw与decoded hash可供核对；网页未来改版不能把新字节假装成原捕获。公开审计报告的原审核代码hash与便携测试副本的hash可以不同，便携副本仅调整路径/输出，不改断言；独立完整决策oracle保持原字节。

## 4. 从独立输入验证恢复

```sh
python scripts/recover.py --input "$SECOND_INPUT" --reference "$PRIVATE/replayed" --target "$PRIVATE/recovered" --receipt "$PRIVATE/recovery-qa.json"
```

新进程不读取reference旧结果来交易；只在生成后逐文件比较。金融内容不允许差异，summary仅允许资源指标峰值RSS不同。指标、信号、全4h净值和所有配置完整交易留私有工作盘；公开轻量结果是确定性投影，月末抽样不参与计算回撤或Sharpe。
