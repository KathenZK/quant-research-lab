# M0288 恢复与独立校验

此流程从官方归档重建私有输入，再执行未修改源类的原生参考引擎。不要把新工作盘当备份；远端保存和回读由协调者负责。保留至少5GiB空闲，所有新输出目录必须不存在；脚本拒绝覆盖。

在 Lab 仓库根目录，先按仓库 `uv.lock` 建立仓库环境（行情QA配套），另建隔离回测环境：

```bash
uv sync --locked --extra dev --extra ml
mkdir -p /tmp/m0288-recovery-new
uv venv /tmp/m0288-recovery-new/env --python 3.12
uv pip install --python /tmp/m0288-recovery-new/env/bin/python -r research/public-strategies/M0288/specs/requirements.lock.txt
.venv/bin/python research/public-strategies/M0288/scripts/rebuild_inputs.py --out /tmp/m0288-recovery-new/inputs
/tmp/m0288-recovery-new/env/bin/python research/public-strategies/M0288/scripts/run_replay.py --input /tmp/m0288-recovery-new/inputs/staging/input.csv --source /tmp/m0288-recovery-new/inputs/PatternRecognition.py --out /tmp/m0288-recovery-new/results
/tmp/m0288-recovery-new/env/bin/python research/public-strategies/M0288/scripts/validate_replay.py --input /tmp/m0288-recovery-new/inputs/staging/input.csv --source /tmp/m0288-recovery-new/inputs/PatternRecognition.py --run /tmp/m0288-recovery-new/results --out /tmp/m0288-recovery-new/validation.json
/tmp/m0288-recovery-new/env/bin/python research/public-strategies/M0288/scripts/verify_recovery.py --rebuilt /tmp/m0288-recovery-new/results --out /tmp/m0288-recovery-new/recovery-check.json
```

`rebuild_inputs.py`复用已入库 M0216 `fetch_inputs.py`，先验证其哈希，不复制另造行情平台；仓库环境提供它所需的PyYAML等完整依赖。实际第一次尝试使用只装交易依赖的隔离环境在导入PyYAML前失败，尚未下载输入；第二次使用仓库环境通过，未绕过任何数据检查。

下载25个2022-12至2024-12的官方日K月归档及其CHECKSUM，规范CSV必须得到SHA256 `48e4e785ee3366a459cf09f64617c89e04fb19b91da6c6125e86835506f6b9f5`；原策略重取必须得到SHA256 `cce61e4af8ed3cb8e78a5d9713aba7891ec08d1bdb1da9911c3f550424db795d`。官方数据或代码修订造成不一致时直接停止，不能自动接受新字节替换原证据。公网来源未来可用性无保证。

`verify_recovery.py`与[冻结清单](../artifacts/20261003-first-replay/result-manifest.json)比对全部10个完整结果文件，包括4份逐配置日净值、4份成交、买持日净值及汇总。正式恢复验收还应核验独立验证文件中的PASS状态，不把仅哈希相同理解成真实交易可行。

执行引擎检查了固定 Freqtrade2026.9 的关键模块字节；环境与额外记账模块见[环境](../specs/environment.json)。已验证的执行平台为Linux/Python3.12.14、TA-Lib0.6.8/C0.6.4、Pandas2.2.3、Numpy2.3.5，未验证其他平台的浮点逐字节一致性。

[Graph导出脚本](../scripts/export_graph.py)需要原独立验证及恢复回执，生成11个轻量证据文件和独立私有详情；不会写Graph数据库、修改UI或发布站点。已有artifact必须保留，不以重新导出的文件覆盖。协调者整合时需给11个非Markdown artifact添加精确allowlist，给M0288加两个研究索引，并按明确现货diagnostic消费登记脚本；执行者没有修改这些全局文件。
