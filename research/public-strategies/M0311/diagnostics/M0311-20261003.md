# M0311：CMF21 原信号与声明执行代理的失败诊断

**本次执行代理显著失败，不晋升。** 基础配置在 2024 年产生 5699 次完整交易，初始 100000 USDT 降至约 4.235 USDT；零手续费但保留双边 2 bps 滑点的配置仍亏损 75.22%。这是 **ADAPTED_EXECUTION_PROXY** 的结果，不能称原限价策略严格复现或推断原限价策略已得到相同收益。

## 原始来源与研究假设

稳定 ID M0311，TechnicalExampleStrategy。原源位于 freqtrade/freqtrade-strategies 提交 `f3340ce11f5bdf62f598522e64d1f5638eaa13f5` 的 `user_data/strategies/berlinguyinca/TechnicalExampleStrategy.py`。原字节 1069 B，SHA256 `0a3d94c8ef857284c9bc37d592af329b1a831f9c504fb2d73b63db00d303db50`。源码没有声明个人作者、论文、交易池或完整运行配置。原文关键规则及 GitHub 出处见[公开来源说明](../specs/source-description.json)；完整原字节保存在私有证据包内。

原指标通过 `cmf(dataframe, 21)` 调用，固定 technical 提交 `8ce873e269bfbfe0d17d487a3e5163616ec0a872` 的 `volume_indicators.py`，SHA256 `8bfa4fd42727396c01b35f3ef4a651778612798acaf0788bb0915313afe909d5`。cmf 是 chaikin_money_flow 别名：

`CMF21 = rolling_sum21(volume × ((close−low)−(high−close))/(high−low)) / rolling_sum21(volume)`。

白话是以成交量加权观察收盘位置：偏向区间底部时买入，转向上部时退出。可以把它解释为卖压后的反转假说，但原文件没有论证该经济机制，不能仅因名称带“资金流”就当作真实资金流因果证据。原目录描述遗漏了周期 21，本研究以原代码为准。

原默认设置以固定 Freqtrade 2026.9（提交 `1f394eaebc2f46a83d26971388628707802f8602`）的 interface/resolver/hyper 原码和实际安装模块哈希交叉核验，不代表找到了作者当时环境。原模块导入后，将其 cmf 依赖绑定到固定 technical 函数，源码字节未改。实际原 `min_roi_reached` 在利润恰好 0.01 时为 False，nextafter(0.01,+∞) 为 True。源码没有外部参数文件，并不证明作者运行时没有外部配置；本次明确不加载外部参数。

代理顺序：已到期信号退出优先，不要求盈利；随后空仓买入；持仓先判开盘止损跳空、再判开盘严格 ROI，然后柱内止损优先于 ROI。同柱退出不重入。止损价=入场成交价×0.95；ROI 阈值=入场成交价×(1+费率)×1.01/(1−费率)，high 或 open 必须严格超过阈值，实际卖出再扣滑点与卖费。因此触及阈值与成交后净收益不是同一个数。全程不强制末日卖出，买持和策略都按最终原始收盘价标记未平仓头寸。

合成案例明确证明：价格从未触及 99 的买限价单不会成交，但下一开盘 100 的代理会买；跌至 90 时 95 的卖限价无法立即兑现，而代理以跳空价卖出。**这些差异构成 ADAPTED 分类，不以信号一致性掩盖。**

结论为**原信号＋当前代理执行失败，禁止晋升**；不等于替未定义的原限价执行下定论。继续研究应先获得原挂单价格、超时、成交规则和历史约束；再为真实限价模型与独立窗口预注册。若增加迟滞区间、交叉条件、降低换手或改变仓位，均属新规则，应另冻结 ADAPTED 变体；本次没有这些实验。Graph 只准备既有详情／比较页兼容输入，未导入或部署。
