## 精确执行口径

固定 BTCUSDT **现货**，不是 BTCUSD 或永续。SMA11 与 SMA20 使用当根已闭合日线；前根短均线≤长均线而当前>时买，反向≥到<时卖，平时保持。一仓只多，现金无息。初始化100000 USDT，买入名义金额为现金95%，另扣费；卖出全部数量。信号后下一日开盘全额成交；每边手续费8bps，买价上调/卖价下调2bps，允许小数数量，不建模盘口冲击与历史最小下单量。

公开 README 给日频11/20和95%/15%/5%风控；公开回测入口含其他默认值、优化循环和8bps费率，未把其历史53.42%等指标当本次结果。我们只固定11/20、不执行源码、不运行优化。统一上述来源并补充成交/滑点假设，因此 fidelity=HYPOTHESIS，strict=false。

关键源码语义：风险检查位于买卖信号之前。15%峰值回撤触发永久暂停**所有新指令**，不主动卖出；本次保持该行为。日频每次收盘都刷新当日初始权益，5%日损门在此采样下无效，不能称已限制日内损失。风险线不是止损成交价。不做期末强平，期末浮动持仓纳入净值。
