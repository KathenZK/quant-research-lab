# M0317 mabStra 默认阈值回放报告

## 结论

在固定BTCUSDT现货4h、2023至2024年窗口内，源码默认SMA比值条件每根都满足买入，指标卖出条件恒为假。本实例实际上长期持仓，并由ROI和止损反复退出再进入；它不能证明作者要求hyperopt后的策略表现。8bps单边费、2bps不利滑点、95%含费预算的主情景净收益304.99%，低于同预算买持441.87%，且回撤更深、日Sharpe更低。

所有结果保持 **HYPOTHESIS / DIAGNOSTIC_ONLY / strict_reproductions=0**。仅完成源默认规则的已声明执行代理，不晋升、不宣称OOS或实盘就绪。窗口在M0256、M0275等历史研究中已经曝光；历史总搜索次数未知，不能据此计算可靠DSR/PBO。本报告没有根据收益改参数或窗口。

## 源规则和已知缺陷

来源是Masoud Azizi（Mablue）的[mabStra.py固定版本](https://github.com/freqtrade/freqtrade-strategies/blob/f3340ce11f5bdf62f598522e64d1f5638eaa13f5/user_data/strategies/mabStra.py)，4044B，SHA256为1c483a549398a0244ca6d87f9736a76ed462056aca8a5ee9affd9aa65efd9393。主目录原M0317行的文件/策略身份一致，未新建ID。

- 指标为收盘价SMA7、SMA14、SMA28，买卖两组周期一致
- 入场要求SMA7/SMA14和SMA14/SMA28都严格介于0.2950和2.2545之间
- 指标出场要求SMA14/SMA7和SMA28/SMA14同时大于2.8144且小于1.5459，对有限比值不可能成立
- 四位小数来自原DecimalParameter构造器的实际round行为；源码写入的0.29497、2.25446、1.54593、2.81436分别变为0.2950、2.2545、1.5459、2.8144。声明优化区间0到2没有在初始化时拒绝/钳制越界值
- 原ROI以分钟为键：0→59.8%、644→16.6%、3269→11.5%、7289→0；固定止损−12.8%
- 源码无trailing覆盖。固定Freqtrade框架c66e221的IStrategy默认False，已独立核对
- 作者注明需hyperopt，却没有buy_params/sell_params字典。保留原默认数值仅供代码质量诊断，不能称为作者优化配置的复原

[源码/参数/信号C0](../artifacts/C0-source-signals.json)执行原策略类AST、原参数构造器AST及独立pandas rolling校验，并验证103个前缀。它不是完整Freqtrade resolver启动或其引擎对拍。源码卖出空区间、超优化越界默认值、作者要求调优三项都没有被静默修补。

原类没有订单覆盖，框架默认entry/exit/stoploss为limit，GTC。本诊断显式采用全量market代理成交，单边不利滑点2bps；没有复制limit排队、盘口或历史最小订单约束。运行假设包括ignore_roi_if_entry_signal=False，因此持续买入信号不屏蔽ROI。价格缺口先按可观察开盘价处理；随后若高低同时触及止损与ROI，止损优先；同根卖出后不再次入场。

ROI年龄是有效入场时刻起的墙钟整数分钟，在可观察开盘选择档位、整根保持。644、3269、7289分钟边界若落在根内，只在下一有效开盘才采用新档，不用更早发生的整根高点套新目标。ROI目标价为entry_fill×(1+entry_fee)×(1+ROI)/(1−exit_fee)，执行再扣不利滑点，故ROI0实际可有小额亏损；止损基于entry_fill×0.872，卖出成本另计。
