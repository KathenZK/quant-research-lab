# M3710｜每日收盘价与 SMA20 的状态择时

一句话：当比特币收盘价站在最近 20 日均价之上时持币，回到均价或其下方时持有零收益现金。

## 来源与复现身份

目录记录稳定 ID 为 M3710，原 11 字段文件 SHA256 为 `48f256ba95983a82b57e63b23060a43c1257f6ce726a4840c29c6c0f69db413c`，规则文本 UTF-8 SHA256 为 `c3a2757961fcbc207aff5ba2aea0ac9d1a9fa4c3e765b140a9d845e41f381ad9`。完整原记录及内部编目留私有。

目录转述的操作摘要为日频价格高于 SMA20 持 BTC、低于或等于持现金/T-bill；此处不是作者原文引语，也不是 50/200 均线交叉。来源指向 [CXO Timing Bitcoin with SMAs](https://www.cxoadvisory.com/technical-trading/timing-bitcoin-with-smas/)。本次 CXO、SSRN 与 Wiley 各一次直接读取返回 403 后即停止。作者主页只能确认 Detzel、Liu、Strauss、Zhou、Zhu 的相关论文书目；论文正文、原 2018 版本及目录报告日期 2018-03-01 未核实。[完整安全来源审查](specs/source-review.safe.json)。

因此本实验为目录假设的执行适配，不能称严格复现。包含当日 close 的均线、现金零收益、市场与账户选择均明确由协调者冻结，不能归因于原作者。

## 固定规则与算法

| 项目 | 本实验选择 |
| --- | --- |
| 标的与选池 | Binance 现货 BTCUSDT，单一标的，无动态选池、杠杆或借款 |
| 周期 | 原生 UTC 日线；时间戳表示开盘日期 |
| 均线 | `SMA20[t] = (close[t-19] + ... + close[t]) / 20`，每个窗口从左到右重新求和 |
| 数值 | 原始十进制文本转 Decimal50、ROUND_HALF_EVEN；不使用浮点比较或 epsilon |
| 就绪 | 全输入索引 19 首次就绪；此前指标空值、原始入场与出场均为 0 |
| 原始入场 | 当前 close 严格大于 SMA20；是状态条件，不要求前一天发生交叉 |
| 原始出场 | 当前 close 小于或等于 SMA20，等于时退出 |
| 仓位 | 初始 100000 USDT，100% 含费现金预算，允许碎股；买入本金=`cash/(1+fee_rate)`，费用=`cash-本金` |
| 现金 | 零收益，不模拟 T-bill 利率、利息或资金费率 |
| 其他风险规则 | 不添加止损、ROI、斜率或成交量过滤器 |

复用未改动的 [catalog-daily-cash v1](../../_shared-kernels/catalog-daily-cash/README.md)，精确四件指纹见 [kernel pin](specs/kernel-pin.json)。买入以实际成交开盘价及滑点计算数量；卖出按持币数量计算本金与手续费。冻结 Decimal 运算顺序，现金不得靠负数裁剪或容差修补。

## 时钟、预热与索引

完整输入为 2022-09-23 至 2024-12-31 的 831 根日线，前 100 根只初始化指标，禁止带入订单或持仓。2023-01-01 开盘以纯现金开始；首次决策在该日完整收盘后。基本配置最早 2023-01-02 开盘成交，delay2 最早 2023-01-03 开盘成交。

先对完整 831 行计算 SMA，再用共享薄适配器投影至从 2022-12-01 起的 762 行账户视图。偏移为 69；账户内核的 `input_index=31` 对应全输入 `canonical_feature_index=100` 及 `eval_index=0`。指标不得在 762 行视图重新初始化。订单的 `signal_index/due_index` 和交易的入出场索引属于评价索引空间，完整映射单独输出。

开盘先执行到期且持仓允许的旧订单；收盘先根据原始反向状态取消相反订单，再依据实际持仓决定新订单。同向重复保持最早到期时间，无事件不取消已有订单。末端未成交意图保留，不补未来价格；期末按最后真实收盘价估值，不强平，也不扣未发生的退出费用。

## 当前证据、结论与失败场景

当前没有真实指标、净值、成交或质量排名：尚未获得对精确 C0 的历史运行授权。人工合成覆盖就绪、恒价相等、上涨/下跌状态、Fraction 逐步舍入、未来扰动、预热隔离、订单取消/延迟、全现金预算、完整账户、指标及输出一致性。合成通过只证明这些实现边界，不证明策略有效。

经济假设是趋势持续时，均线上方持币可能保留上涨并避开部分持续下跌。震荡反复穿越会产生费用，急跌与跳空由下一开盘承担，V 形反转可能错失反弹，现金零收益也会改变与原文现金/T-bill 的比较。后续先执行已冻结配置并独立核验；若要补作者原文、替换现金利率、扩样本或调整参数，必须另立版本，不能按结果回改本合同。
