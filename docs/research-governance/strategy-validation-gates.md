# 研究验证与状态迁移

本文件区分研究证据、实现合同和运行授权。普通研究按问题选择验证方法，不要求先完成一套通用 promotion review；状态字段见 [状态术语表](strategy-status-glossary.md)。

## 证据原则

- 数据来源、质量和消费方式遵循 [数据湖规范](../data-lake-spec.md)；数据契约检查、文件存在或测试通过，不代表研究结论已验证。
- 评估依据和结论边界写入本研究规格/报告。冻结的输入、参数、OOS、成本与验收要求继续有效；修改它们需要可追溯的新规格，不能看过结果后回改门槛。
- 分析方法由研究问题决定，参考 [研究方法](research-methods.md)。基准、消融、OOS、Monte Carlo 和压力分析不再是所有研究都必须齐备的固定套餐；省略某方法不等于该方面已经通过。
- 声称泛化、可交易或可上线时，提供与该声明相称的证据。已知前视、不可执行成交、未解决复现或对账偏差不能用其他绩效指标抵消。

## 按目标记录

| 当前目标 | 需要落实的内容 |
| --- | --- |
| 探索、诊断、代码或数据审计 | 回答当前问题，保存相关证据和限制；不自动登记版本或启动晋升流程 |
| 登记/冻结版本 | 主账记录版本身份、冻结规格与证据链接；登记本身不表示可交易，也不触发额外实验或图表 |
| 写 runner 交接规格 | 身份与参数明确，数据和状态机可复现，规格符合 [交接格式](lab-runner-handoff.md) |
| 进入 dry-run | 用户授权、runner 实现及对拍或 smoke 证据，并建立 runner-tracking；live spec 可作为中间态，不要求先完成整套研究方法 |
| 进入 live | 用户授权和资金边界明确；策略执行/风险假设有证据支持；dry-run 观察与线上开平仓对账完成，无未解决重大偏差；保护单、重启恢复、缺失数据和紧急停止行为已核验 |

生产运行按 quant-runner 的授权与配置执行。文档、CI 或证据缺口应如实报告，不自动改变已有实例；离线 parity 和 smoke 不能替代 live 所需的线上对账。

## 报告与历史兼容

报告写清问题或迁移目标、冻结依据、执行了什么、结果与不足，并链接规格、脚本和产物；主账与 decision log 记录因此发生的版本或状态决策。字段按研究需要组织，不要求每份报告套同一组指标。

2026-09-08 起，取消仓库统一的方法套餐、窗口/组数和参数扫描要求，改由本研究契约和具体风险决定。已经冻结的研究合同与历史 Gate 0–5/6/7 编号保留当时含义；不重写历史结论，也不把旧套餐继承到新研究。
