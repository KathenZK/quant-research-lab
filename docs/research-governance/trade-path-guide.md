# 研究图表参考

图表用于回答具体问题。用户要求或图表能帮助判断时再生成；登记版本、改参数、运行回测本身不触发出图。

- 按问题选择静态图、交互图、局部窗口或完整路径，不预设 HTML、全历史、指标面板和交易表必须全部出现。
- 用保留的实际数据和结果生成；价格、权益与交易记录应能追溯到同一回测口径，不从叙述重建交易。
- 用于逐笔核验时确认交易 ID、开平仓时间与端点对应，区分反手和多空；展示全部交易时与保留结果的交易数一致，展示子集时标明范围。
- 保留产物放家族 `artifacts/`，需要复现的生成脚本放 `scripts/`；确认文件可打开、显示完整并在对应报告中链接。选择自包含 HTML 时不要依赖本地开发服务器。
