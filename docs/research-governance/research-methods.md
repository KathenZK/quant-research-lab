# 研究方法参考

本文件提供方法选择参考，不是每项任务都要执行的清单。先围绕用户的问题和已冻结的研究契约取证；只开展能改变判断或验证实现的分析。

- **成本与执行**：采用本研究市场、订单类型和交易规模对应的成本假设，写明手续费、滑点、资金费率/持有成本、成交时序。缺少依据时明确假设及其限制，不隐式套用其他市场或历史策略的数值。
- **历史默认值**：旧通用 Binance 假设为每次成交 `0.001` 手续费加 `4 bps` 不利滑点。这只用于识别旧报告；新研究自行确定并记录适用模型。冻结复现沿用原契约，不能因本次规则精简改算历史收益。
- **评估窗口**：按持仓周期、独立样本量和市场阶段选取。旧 `1d / 7d / 1m / 3m / 6m / 1y` 切片不是新研究的固定套餐；若使用近期切片，注明数据末端、真实覆盖和零交易窗口。
- **基准与归因**：比较能回答原问题的基准；需要区分某个部件贡献时做消融，不要求每次拆遍全部参数。
- **泛化**：根据标签跨度、重叠、选参过程与可用历史选择 holdout、walk-forward、CPCV 或其他适用方法。报告哪些数据参与选择、哪些保持未见；反复使用的历史不称为新的盲测。
- **稳健性与压力**：对结论最依赖的参数、成本或执行假设做针对性验证。Monte Carlo、相位、起跑点扫描均为可选工具，不要求固定套数、窗口或阈值。
- **结果边界**：数据缺口、复现失败、不可执行的成交或样本不足应直接说明。完成方法清单不证明结论成立，方法未使用也不自动构成失败。

涉及版本状态推进时，见 [研究验证与状态迁移](strategy-validation-gates.md)；图表按 [图表参考](trade-path-guide.md) 选择。
